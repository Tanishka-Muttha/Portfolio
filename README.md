# Tanishka Muttha — Personal Portfolio (React + Vite)

A complete, production-quality personal portfolio website built with React 18, Vite, and vanilla CSS for **Tanishka Muttha**, Information Technology engineering student at D.Y. Patil College of Engineering, Akurdi, Pune (2023–2027).

## Available Scripts

- `npm install` — Installs dependencies
- `npm run dev` — Runs the local development server at http://localhost:5173 with hot reload
- `npm run build` — Builds the optimized production bundle in `dist/`
- `npm run preview` — Previews the production build locally
